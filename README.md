# XproSupport

Проект складається з трьох основних частин:
- **API** 
- **Telegram бот** 
- **Frontend** 

---

## 🚀 Швидкий старт та опис компонентів

### 1. API (Бекенд)
При запуску API та застосуванні міграцій створюється база даних, яка автоматично заповнюється тестовими даними (користувач admin i темами). 

### 2. Telegram Бот
Бот відповідає за комунікацію з кінцевими користувачами.

**ВІДПОВІДІ НА ТІКЕТИ ПРАЦЮВАТИМУТЬ ЛИШЕ В ДОДАНИХ ГРУПАХ ЧЕРЕЗ БОТА ЗІ СПРАВЖНІМИ ID ГРУПИ. 
ЯКЩО ВІДПОВІСТИ НА НЕСПРАВЖНІЙ ТІКЕТ ТО БОТ ВПАДЕ**

**Як тестувати:**
1. Створіть нову Telegram групу (або візьміть існуючу) і додайте туди вашого бота.
2. Використайте команду `/support` (через меню або ввівши вручну), щоб звернутись у підтримку.
3. Бот перейде до процесу вибору теми та створення тікету в групі.
